# Regression corpus

`manifest.json` pins the SHA-256 and byte count of each book, synthetic input,
and compatibility snapshot. Tests use committed files without downloading books.

## Fixture types

- `synthetic/`: MIT-licensed parser cases generated by `build.py`, including Unicode, encodings, EPUB images, and footnotes.
- `snapshots/aq_complete/`: a completed public-domain 阿Q snapshot, with personal metadata, settings, and runtime logs excluded.
- `snapshots/aq_annotated/`: the completed snapshot plus a synthetic note written through the reference notebook API.
- `snapshots/aq_paused_annotated/`: an offline replay paused after four segments, with an API-generated synthetic note.
- `snapshots/aq_notebook_history/`: API-generated create, edit, conflict, delete, export, and restore cases using synthetic notes.
- `snapshots/aq_notebook_overlay.json`: a synthetic note anchored to the public-domain source text.

The generated note fixtures contain no reader’s personal notes. Their manifests
pin input and implementation hashes; preserve those when verifying provenance.

## Verify and rebuild

From `reference/`, using Python 3.11:

```sh
python3 oracle/corpus/build.py --verify
python3 oracle/corpus/annotate_snapshot.py --verify
python3 -m oracle.corpus.paused_annotated_snapshot --verify
python3 -m oracle.corpus.notebook_history --verify
```

Verification uses local files. To rebuild source books and synthetic inputs,
use `python3 oracle/corpus/build.py --source-dir /path/to/pinned-downloads`.
The inputs must be named `aq.txt`, `jekyll.txt`, `rulin.txt`, `french.txt`, and
`kokoro.zip`. Without `--source-dir`, the builder fetches the pinned URLs and
rejects changed hashes. Review source rights before replacing any input or
redistributing a new edition. Never capture a library containing private notes.
