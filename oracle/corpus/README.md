# A0 corpus

This directory contains fixed inputs for the Python 1.7.5 oracle and the Dart
port. `manifest.json` records the SHA-256 and byte count of **every** book,
synthetic input, and compatibility snapshot file. It also pins the upstream
download bytes. The checked-in files are the actual test inputs; network access
is unnecessary to run goldens or verify them.

## Synthetic inputs

All files in `synthetic/` are generated by `build.py` and follow this
repository's MIT license. The text cases cover extension-plane Han characters,
emoji including ZWJ sequences, combining marks, full-width and non-breaking
spaces, CR/LF/CRLF plus Unicode separators, empty input, heading-only chapters,
preface-only content, one paragraph over 100,000 characters, and GBK, UTF-8
BOM, UTF-16 LE and UTF-16 BE. The empty TXT is an expected parser rejection.

`footnote_illustration.epub` contains an earlier footnote reference and a later
note body, a real embedded PNG over the parser's size threshold, a cover image,
and an empty chapter. `scrambled_toc.epub` has a navigation order that differs
from the spine, a missing target, and a nested chapter. Both ZIPs use fixed
timestamps and generated images, so their bytes rebuild identically.

## 1.7.x compatibility snapshots

`snapshots/aq_complete/` and `snapshots/bovary_partial/` are frozen copies of
actual 1.7.x data directories from the local library. The former is completed;
the latter is paused after 20 of 73 segments and retains its partial `work/`
cache. They contain only public-domain book text and historical generated
artifacts. The capture allowlist includes `book.json`, `kg.json`, `status.json`,
available `source.txt`, and JSON files under `work/` and `mentions/`. It excludes
personal shelf metadata, runtime logs, PID/lock files, settings, and notebooks.
All copied bytes were scanned for common key and credential formats; the
manifest pins the resulting exact files.

`snapshots/aq_notebook_overlay.json` is a **synthetic** 1.7.x-format note with a
verified UTF-16 quote anchor into the real 阿Q snapshot. Apply it as
`notebook.json` to a copy of `aq_complete/` for the annotated upgrade case.
The only actual annotated data directory in the accessible local library is a
copyrighted web novel, so it is intentionally excluded. This overlay covers
the notebook schema and anchor contract, but it is not evidence that an actual
annotated 1.7.x directory upgraded successfully.

These fixtures are snapshots for compatibility testing, not a backup of the
live library. No live service files were changed during capture.

## Rebuild and verify

From the repository root:

```sh
python3 oracle/corpus/build.py --verify
python3 oracle/corpus/build.py --source-dir /path/to/pinned-downloads
```

`--verify` reads local files only and checks the manifest. The second command
recreates published-book and synthetic inputs and refreshes the manifest; the
five pinned downloads must be named `aq.txt`, `jekyll.txt`, `rulin.txt`,
`french.txt`, and `kokoro.zip`. Without `--source-dir`, the builder fetches the
recorded URLs and refuses any upstream edition whose SHA-256 has changed.
Review a source and its rights before updating a pinned hash. To deliberately
recapture the two local snapshots, also pass
`--snapshot-root /path/to/1.7.x/books`; this replaces the checked-in copies
with the selected source IDs. Do not recapture from a library containing
private notes or a different book edition.

For the initial capture, `--verify` confirmed 117 data files totaling
3,401,626 bytes. Python `parse_file` read every nonempty text and both EPUBs;
it extracted one footnote and both generated PNGs. `server.notebook.restore`
accepted the synthetic note with an exact UTF-16 source quote.
