## 文案与行为约束

“暂未言明”只用于确实缺少文本证据的判断；网络错误明确提示重试。AI 共读视角不冒充真人评论。标记读完不扩大人物知识范围。同步入口准确说明手动快照，不假称实时同步。角色和引用沿用已有防剧透证据边界。

竞品功能按本地阅读产品能力归类。内容商城、版权书库、打赏、月票和真人社交需要独立内容与账号服务，不以空按钮充数。

## 设计与交互结果

| 用户路径 | 最终行为 |
| --- | --- |
| 进入书架 | 页读与一句标语；添书、搜书、在读清单和全部藏书形成主次。梳理状态跟随单书卡片。 |
| 管理藏书 | 分类可增改移除，读完可手动标记。分类和读完不改变阅读进度或人物截止。 |
| 打开书页 | 正文保持稳定。中央轻点唤出上下工具，4%遮罩压低背景；退出工具不改变排版。 |
| 查目录与跳转 | 未读前跳提醒剧透，往前回看说明资料范围收窄；取消保留原位置。 |
| 选择原文 | 划线、写想法、这是谁、问这段按当前原文范围工作。识别响应不会串到新选区。 |
| 查看人物 | 本页、本章、全书、关系统一范围控件；别名、初次登场、次数聚在姓名下方。资料保留来源证据。 |
| 回顾与提问 | 此前脉络和本章进展分开。问书以原文出处回跳，并限制在当前已读范围。 |
| 改排版 | 常用四字名称、对齐数值与统一边距。保留字距、段距、缩进、音量键等已有能力。 |
| 看书摘 | 全部、划线、想法、书签；按书名、作者和内容搜索，复制或导出当前筛选结果。 |
| 听书 | 使用设备语音服务，支持语速与定时。只按实际读出的原文推进截止；手动翻页或进入后台停止/暂停。 |
| 自动阅读 | 自动翻页可调整间隔与时限；打开其他面板或触摸正文暂停。自动翻页不伪造阅读活动。 |
| 阅读记录 | 本设备前台阅读才计时，空闲90秒后停止累计；跨午夜拆分，重叠阅读窗口不重复计时。 |
| 保存与搬家 | 单书与全库备份保留分类、读完、书摘类型及原文选区。网页记录精确原文位置，旧备份继续兼容。 |

## 明确保留的能力边界

- 网页支持连续滚动；Android 本轮保留分页并加入自动翻页。没有把竖向分页称为连续滚动。
- 阅读统计保存在本设备。已有 WebDAV 是手动快照，没有改称账号实时同步。
- 系统听书依赖设备提供对应语言语音。缺失时给出可操作提示，不静默显示播放成功。
- AI 共读视角是生成的读书评论，不是真人社区。仍保留服务费用和文本发送范围说明。
