# 自行托管页读网页版

页读网页版是一组静态文件。GitHub Pages、普通静态文件托管或自己的静态网站都能分发它；阅读器不需要页读服务端，也不需要数据库服务。安装版在各自设备上运行和保存书库。

## 构建与发布

需要 Flutter 3.47.5 和 Dart 3.13.4。在仓库根目录执行：

    cd app
    flutter pub get
    flutter build web --release --target lib/main_web.dart --base-href /thusfar/
    cd ..
    python3 app/web/prepare_offline.py app/build/web

把 app/build/web 的内容部署在网站的 /thusfar/ 路径。若使用其他路径，请把命令中的 --base-href 改成实际路径（首尾都带斜杠）。此仓库的 GitHub Pages 工作流在 main 分支的 app、core 或工作流文件变化时自动构建并部署，也可以手动运行。

建议使用 HTTPS 和固定网址。浏览器把书籍、摘记、进度和整理结果保存在这个网址所属来源的本地存储中；在同一网址更新静态文件不会清空这些数据。换域名、换浏览器或清除网站数据都不是同一份本地书库。

## 带走整套书库

在书架下载整库 ZIP，然后在另一个页读客户端导入。ZIP 包含书籍、图片、书签、摘记、阅读位置、整理资料及可迁移的阅读和模型设置。正在整理时请先暂停并等待当前模型请求结束，再导出整库。单书 JSON 备份也仍可导入。导入已有书籍时会合并兼容资料；冲突会明确显示，不会静默覆盖原资料。

单独填写的模型 API 密钥不会放进 ZIP，导入后需要重新填写。自定义模型地址可能在路径中包含敏感信息，因此 ZIP 应作为私人资料保管。也可以手动使用自己的 HTTPS WebDAV 文件夹传递书籍快照；从网页版连接 WebDAV 时，WebDAV 服务须允许该网页来源跨域访问。

## 模型连接

读书和导入书籍无需模型。主动整理人物线索或问书时，网页版直接从用户的浏览器向所选模型服务商发请求；GitHub Pages 不提供模型额度。可选 OpenAI 兼容、Gemini 与 Claude 兼容协议，也能编辑接口地址和模型名称。模型服务商必须允许浏览器跨域请求，且网络需要能连接它。浏览器的 API 密钥仅保存在当前标签页内存中，刷新后需重填。

安装版在设备的私有目录保存用户填写的密钥。安装版的人物资料核对流程与网页版的带引文草稿有区别；请按界面标注使用结果。详情见仓库首页的功能和数据说明。
